MODEL SYSTEM / DEVELOPER INTERFACE

IDRIS النموذج وواجهات API

هذه الصفحة هي المرجع الرسمي لحالة النموذج وخطة إتاحته للمطورين. سننشر تفاصيل checkpoint والتراخيص والتقييم وواجهات الاستخدام هنا عندما تصبح موثقة وجاهزة.

الحالة الحالية: لا يوجد إصدار عام للنموذجلم يُعلن بعد عن checkpoint مدرّب أو أوزان منشورة أو endpoint متاح. لا تستخدم أمثلة API أدناه باعتبارها خدمة قائمة.
01 / MODEL RELEASE

بوابات إصدار النموذج

  • اختيار نموذج أساس ومراجعة ترخيصه وإصدار revision ثابت.
  • تشغيل تجارب قابلة لإعادة الإنتاج وتوثيق إعداداتها.
  • نشر نتائج تقييم تشمل النص العربي وArabizi والمزج اللغوي.
  • إكمال Model Card ومراجعة الخصوصية والسلامة.
NOT RELEASED
02 / API ROADMAP

واجهات المطورين المخطط لها

  • توليد نص بالدارجة مع تحديد اللغة/الكتابة.
  • تحليل النص وتصنيف اللغة أو نمط المزج.
  • تقييم الجودة وإرجاع بيانات وصفية واضحة.
  • توثيق المصادقة والحصص وحدود الاستخدام.
PLANNED
