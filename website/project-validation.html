PROJECT VALIDATION / EVIDENCE BEFORE SCALE

هل يستحق IDRIS أن نبنيه؟

خارطة طريق لاختبار الحاجة الحقيقية، والميزة التقنية، وحقوق البيانات، والقيمة للمستخدمين قبل استثمار الوقت والموارد في تدريب نموذج مستقل أو التوسع إلى لغات أخرى.

هذه خطة تحقق مقترحة وليست نتيجة دراسة سوق أو Benchmark منجز. لا توجد حتى الآن نتائج تدريب أو تفوق مثبتة لـ IDRIS. الهدف هو السماح بالاستمرار أو التعديل أو التوقف بناءً على الأدلة.
01 / THE HYPOTHESIS

ما الذي نحاول إثباته؟

USER NEED

حاجة حقيقية

مشكلة متكررة في فهم الدارجة لا تعالجها الأدوات الحالية بما يكفي.

DATA ADVANTAGE

بيانات موثوقة

محتوى دارج أصيل أو مرخص، متنوع، قابل للتتبع ومراجع.

TECHNICAL EDGE

ميزة قابلة للقياس

أداء أفضل من النماذج العامة في مهام محددة، لا مجرد نموذج باسم مختلف.

02 / VALIDATION GATES

مراحل الاختبار وبوابات القرار

V0

اكتشاف المشكلة — أسبوعان

15–25 مقابلة مع مستخدمين محتملين، تحديد 2–3 فئات وثلاث حالات استخدام. القرار: هل توجد حاجة متكررة؟

V1

اختبار البدائل — أسبوعان

100–200 حالة اختبار ومقارنة عمياء مع نماذج عامة. القرار: هل توجد فجوة أداء تستحق نموذجاً متخصصاً؟

V2

إثبات البيانات — 3 إلى 6 أسابيع

تدقيق الحقوق، دليل التوسيم، وعينة 1,000–2,000 سجل مراجَع إذا سمحت الحقوق. القرار: هل يمكن إنتاج بيانات جيدة بصورة مستدامة؟

V3

الإثبات التقني — 2 إلى 3 أسابيع

قياس نموذج أساسي ثم تجربة SFT/QLoRA صغيرة. القرار: هل يوجد تحسن متكرر دون تراجعات غير مقبولة؟

V4

اختبار قيمة المستخدم — 3 إلى 4 أسابيع

نموذج أولي محدود مع 20–30 مستخدماً. القرار: هل ينجزون مهمة حقيقية بشكل أفضل ويعودون للاستخدام؟

V5

قرار الاستثمار — أسبوع

تقرير نهائي يختار GO أو PIVOT أو HOLD أو STOP مع أسباب وأدلة.

03 / POSSIBLE OUTCOMES

كل نتيجة مقبولة إذا دعمتها الأدلة

GO

حاجة واضحة، ميزة مقاسة، بيانات مشروعة، واستخدام ناجح. نستمر.

PIVOT

المشكلة حقيقية لكن النموذج المستقل ليس الحل الأفضل؛ نبني تطبيقاً أو Adapter أو أدوات تقييم.

HOLD

الفرصة موجودة لكن تنقصنا بيانات أو حقوق أو شركاء أو موارد. نوقف مؤقتاً بشروط عودة واضحة.

STOP

لا حاجة مثبتة أو ميزة أو مسار بيانات مستدام. نوقف بدلاً من استنزاف الموارد.

04 / AFTER DARija

لا توسع قبل إثبات الأساس

الأمازيغية والحسانية ولغة الإشارة المغربية مسارات مستقلة تتطلب شركاء وبيانات وتقييماً خاصاً بها. لا نبدأها لمجرد أنها ضمن الرؤية طويلة المدى.
