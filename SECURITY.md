# Security Policy

## Reporting
Do not disclose exploitable vulnerabilities, credentials, private data, or attack instructions in public issues. Report security concerns privately through the GitHub organization contact channel.

Include the affected component or commit, concise impact description, safe reproduction steps, and suggested mitigation if known. Remove secrets from logs and proof-of-concept material.

## Scope
Reports may concern repository automation, data handling, model-serving examples, dependency risks, accidental secret exposure, or unsafe processing of untrusted input.

The maintainers will acknowledge and investigate reports as reasonably practical and coordinate disclosure with the reporter. No fixed response-time SLA is guaranteed.

Do not access, modify, or exfiltrate data beyond what is necessary to demonstrate a vulnerability. Stop testing if private or sensitive information is encountered.
