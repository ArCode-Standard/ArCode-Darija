# Contributing to IDRIS

We welcome contributions in Moroccan Darija linguistics, dataset governance, preprocessing, evaluation, and model engineering.

## Before contributing
Read the project overview, data policy, and security policy. Check existing issues first. Keep changes focused and explain the motivation.

## Data requirements
Do not submit private, confidential, scraped, or unauthorized material. Every proposed dataset must document its source, license, model-training permission, collection date, language/dialect scope, transformations, privacy review, and limitations. Unknown rights status means the data must remain quarantined.

## Code requirements
- Prefer small, testable Python modules with type hints.
- Add tests for normalization, filtering, and schema changes.
- Record seeds, package versions, and experiment configurations.
- Never commit credentials, model weights, private datasets, or local environment files.

## Pull request checklist
- [ ] Scope and motivation are clear.
- [ ] Tests or validation steps are documented.
- [ ] Data provenance and permissions are addressed.
- [ ] No secrets or restricted data are included.
- [ ] Documentation matches the implementation.

Until an explicit repository license is added, do not assume contributions or repository contents are licensed for unrestricted reuse.
